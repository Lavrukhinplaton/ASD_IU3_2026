## Идеи решений

**29. Мода.** Сортирую копию массива — одинаковые числа оказываются рядом, и остаётся найти
самую длинную группу. Сравнение строгое, поэтому при равной частоте выбирается меньшее число
(оно раньше в отсортированном массиве). Сортировка выбрана вместо двойного цикла (O(n^2)).

**42. Вставка.** Позиция ищется бинарным поиском (индекс первого элемента больше x),
потом элементы копируются в новый массив длины n + 1 со сдвигом.

**44. Чередование знаков.** Положительные и отрицательные числа раскладываются по двум массивам
в исходном порядке, затем записываются в ответ через одного. Если чисел разного знака не поровну
или есть ноль — исключение.

**47. Поворот.** `rotated[j][n - 1 - i] = matrix[i][j]`, результат — новая матрица m x n.

**52. Минимумы столбцов.** Для каждого столбца начальный минимум — его первый элемент,
дальше обычное сравнение.

**54, 55. Диагонали.** Главная диагональ — `matrix[i][i]`, побочная — `matrix[i][n - 1 - i]`.
Сумма в `long`.

**59. Определитель.** Разложение по первой строке через три минора 2 x 2.
Считается в `BigInteger`, потому что произведение трёх `int` не помещается даже в `long`.
