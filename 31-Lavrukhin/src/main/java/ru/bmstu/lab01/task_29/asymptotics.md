# Задача 29. Мода массива — асимптотика

## Решение

1. Делаем копию массива и сортируем её (`Arrays.sort`).
2. После сортировки одинаковые числа идут подряд. Проходим по массиву и считаем длину каждой
   группы одинаковых чисел, запоминаем самую длинную.
3. Сравнение строгое (`count > bestCount`), поэтому при равной частоте остаётся первая группа,
   а так как массив отсортирован по возрастанию — это наименьшее число.

## Время

- копирование — O(n);
- сортировка `Arrays.sort` для `int[]` — O(n log n);
- проход по группам — O(n): внутренний `while` двигает `j` вперёд, а внешний цикл начинает
  со значения `j`, поэтому каждый элемент просматривается один раз.

Итого: **O(n log n)**.

Можно было бы считать частоту каждого элемента двойным циклом, но это O(n^2):
при n = 10^4 это 10^8 сравнений.

## Память

Копия массива — **O(n)**. Копия нужна, чтобы не менять исходный массив.
