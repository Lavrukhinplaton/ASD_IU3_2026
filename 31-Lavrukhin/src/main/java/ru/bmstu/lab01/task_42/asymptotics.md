# Задача 42. Вставка элемента в отсортированный массив — асимптотика

## Решение

1. Бинарным поиском находим позицию — индекс первого элемента, который больше x
   (если x равен каким-то элементам, он встаёт после них).
2. Создаём массив длины n + 1: копируем элементы до позиции, ставим x, копируем остальные со сдвигом на 1.

Перед этим массив проверяется на отсортированность, иначе бинарный поиск даёт неправильный ответ.

## Время

- бинарный поиск: на каждом шаге отрезок поиска уменьшается в 2 раза, шагов не больше log2(n) + 1 —
  **O(log n)**;
- копирование в новый массив — O(n);
- проверка отсортированности — O(n).

Итого: **O(n)**. Быстрее O(n) нельзя, потому что в ответе n + 1 элемент и их все нужно записать.
Бинарный поиск ускоряет именно поиск позиции (O(log n) вместо O(n) при линейном поиске).

## Память

Новый массив длины n + 1 — **O(n)** (это сам ответ), кроме него только несколько переменных — O(1).
