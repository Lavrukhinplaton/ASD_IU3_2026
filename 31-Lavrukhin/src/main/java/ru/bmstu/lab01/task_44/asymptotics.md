# Задача 44. Чередование знаков — асимптотика

## Решение

1. Один проход по массиву: положительные числа записываем в массив `positives`, отрицательные —
   в `negatives`. Так порядок внутри каждой группы сохраняется.
2. В каждом из этих массивов место ровно под n / 2 чисел. Если встретился ноль, или чисел какого-то
   знака больше половины, или n нечётное — выбрасывается исключение.
3. Записываем ответ: на чётные позиции (0, 2, 4, ...) — положительные, на нечётные — отрицательные.

## Время

- раскладка по двум массивам — один проход, O(n);
- сборка ответа — n / 2 итераций, O(n).

Итого: **O(n)**.

## Память

Два вспомогательных массива по n / 2 элементов и массив ответа — **O(n)**.
