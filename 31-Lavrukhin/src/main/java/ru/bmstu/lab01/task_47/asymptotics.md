# Задача 47. Поворот на 90 градусов — асимптотика

## Решение

Создаём новую матрицу m x n и переносим каждый элемент:
`rotated[j][n - 1 - i] = matrix[i][j]`.

Проверка на примере 2 x 3:

```
1 2 3        4 1
4 5 6   ->   5 2
             6 3
```

Первая строка (1 2 3) стала последним столбцом, вторая строка (4 5 6) — первым.

## Время

Два вложенных цикла по всем n * m элементам, каждый переносится один раз — **O(n * m)**.

## Память

Новая матрица m x n — **O(n * m)**. Повернуть на месте можно только квадратную матрицу,
а здесь размеры n x m и m x n разные, поэтому нужен новый массив.
