# Задача 52. Минимум в каждом столбце — асимптотика

## Решение

Для каждого столбца j берём первый элемент `matrix[0][j]` и сравниваем с остальными элементами
этого столбца. Начальное значение — именно первый элемент столбца: если взять 0, ответ будет
неправильным для столбца из одних положительных чисел.

## Время

Внешний цикл — m столбцов, внутренний — n строк. Каждый элемент сравнивается один раз.

Итого: **O(n * m)**.

## Память

Массив из m минимумов (ответ) — **O(m)**, плюс одна переменная `min` — O(1).
