# Задача 54. Сумма главной диагонали — асимптотика

## Решение

На главной диагонали стоят элементы `matrix[i][i]`, i = 0 ... n - 1. Складываем их в одном цикле.
Сумма хранится в `long`: сумма n чисел типа `int` может выйти за пределы `int`.

## Время

- сам подсчёт суммы — n сложений, **O(n)**;
- проверка, что матрица квадратная (все строки длины n) — O(n);
- чтение матрицы в `main` — O(n^2), так как нужно прочитать все n * n чисел.

Итого: алгоритм — **O(n)**, программа целиком вместе с вводом — **O(n^2)**.

## Память

Кроме самой матрицы — одна переменная `sum`, **O(1)**.
