# Задача 55. Сумма побочной диагонали — асимптотика

## Решение

Побочная диагональ идёт из правого верхнего угла в левый нижний. В строке i на ней стоит элемент
из столбца n - 1 - i: для матрицы 3 x 3 это `[0][2]`, `[1][1]`, `[2][0]`.
Складываем эти n элементов в одном цикле, сумма — в `long`.

## Время

- подсчёт суммы — n сложений, **O(n)**;
- проверка, что матрица квадратная — O(n);
- чтение матрицы в `main` — O(n^2).

Итого: алгоритм — **O(n)**, программа целиком вместе с вводом — **O(n^2)**.

## Память

Кроме самой матрицы — одна переменная `sum`, **O(1)**.
