# Задача 59. Определитель матрицы 3x3 — асимптотика

## Решение

Разложение по первой строке:

```
det = a00 * (a11 * a22 - a12 * a21)
    - a01 * (a10 * a22 - a12 * a20)
    + a02 * (a10 * a21 - a11 * a20)
```

В скобках — определители 2 x 2 (миноры), их считает метод `minor`.

Вычисления идут в `BigInteger`. Если элементы близки к `Integer.MAX_VALUE` (~2 * 10^9), то произведение
трёх элементов около 10^28, а `long` вмещает только ~9 * 10^18, то есть даже `long` переполнится.

## Время

Размер матрицы всегда 3 x 3: 9 умножений и 5 сложений/вычитаний — **O(1)**.
Числа в `BigInteger` здесь не больше ~10^29 (около 100 бит), поэтому каждая операция тоже
выполняется за постоянное время.

## Память

Несколько промежуточных значений — **O(1)**.
